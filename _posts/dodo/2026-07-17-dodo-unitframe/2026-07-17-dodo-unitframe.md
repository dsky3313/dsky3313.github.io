## <span style="color:#0b89ff">■ </span> 설명

oUF 기반으로 제작한 커스텀 유닛프레임입니다.

블리자드 기본 플레이어 / 대상 / 주시대상 / 보스 프레임을 비활성화하고 대체합니다.

- 설정 명령어: `/dd` 또는 `/ㅇㅇ`
- 지원 프레임: 플레이어 & 소환수, 대상 & 대상의대상, 주시대상, 우두머리
<br>
<br>

## <span style="color:#0b89ff">■ </span> 기능

### <span style="color:#0b89ff">■ </span> 생명력 & 자원

생명력 색상은 직업, 평판에 따라 변경됩니다.

직업별 자원에 따라 색상이 변경됩니다.

<br>
<br>

### <span style="color:#0b89ff">■ </span> 시전 바

시전 종류에 따라 바 색상이 구분됩니다.

| 상태 | 색상 |
|------|------|
| 시전 (cast) | <span style="color:#ffff00">■</span> 노란색 |
| 채널 (channel) | <span style="color:#63ff63">■</span> 연두색 |
| 중요 스킬 | <span style="color:#ff33c8">■</span> 분홍색 |
| 차단 불가 | <span style="color:#b5b5b5">■</span> 회색 |
| 시전 성공 | <span style="color:#63ff63">■</span> 연두색 |
| 차단 / 실패 | <span style="color:#ff3333">■</span> 빨간색 |

<br>
<br>

### <span style="color:#0b89ff">■ </span> 강화 / 약화효과

생명력 우측 상단에 각 최대 5개까지 표시됩니다.
<br>
<br>

### <span style="color:#0b89ff">■ </span> 편집모드 연동

편집모드에서 위치 수정 가능합니다.
<br>
