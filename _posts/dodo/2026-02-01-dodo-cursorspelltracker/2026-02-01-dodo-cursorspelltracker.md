## <span style="color:#0b89ff">■ </span> 설명

![alt text](cst_option.webp)

현재 직업/특성의 주요 스킬 아이콘을 커서 근처에 표시합니다.

- 설정 명령어: `/dd` 또는 `/ㅇㅇ` > **커서 스펠트래커**

![alt text](cst1.webp){: .normal }

아직 지원하는 기능이 **많이** 없습니다.  
언젠가 추가할 예정...
<br>

표시 정보:

| 정보 | 설명 |
|------|------|
| 쿨다운 스웨이프 | 남은 쿨다운 시각화 |
| 충전수 | 충전 스킬의 현재 충전 수 |
| 버프 글로우 | 특정 버프 활성 시 아이콘 반짝임 |
| 버프 지속시간 | 버프 남은 시간 시각화 |
